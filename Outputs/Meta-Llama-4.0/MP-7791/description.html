Test Case: Searching for records in the Recipients field

Test Case ID

TC-001

Test Scenario

Verify that the search functionality in the Recipients field returns results containing the keyword and groups them by record type/main record.

Test Entry Requirement / Prerequisites

  • User is logged in to the Mojo App
  • Notifications widget is added to the Property Dashboard
  • Test data: keyword/phrase to search for (e.g. "East")

Test Tools

  • N/A

Test Conditions

  • N/A

Test Environment

  • Mojo App
  • Property Dashboard with Notifications widget

Code Deployment Status

  • Current deployment state: latest version

Test Data Validation

  • Verify that the search results contain the keyword/phrase
  • Verify that the search results are grouped by record type/main record

Test Data

  • Keyword/phrase to search for: "East"
  • Expected search results: records containing the keyword "East" grouped by record type/main record

Browser / Device

  • Chrome v120.0.6099.129
  • Edge v120.0.2210.91
  • Firefox v121.0

Test Steps

  1. Open the My Dashboards screen by either using the burger menu on left hand side or the shortcut in the top right corner, under the database / user name dropdown
  2. Navigate to the Property lister page and select a Property record
  3. If the Property Dashboard doesn’t have the Notifications widget, add it using the widget selector
  4. On the Notifications widget click on the Create button
  5. On the pop-up, click onto the Recipients field and type in a keyword/phrase (e.g. "East")

Expected Outcome

  • The list returns results containing the keyword/phrase
  • The search results are grouped by record type/main record

Expected Results

  • Verify that the search results contain the keyword "East"
  • Verify that the search results are grouped by record type/main record

Risk Coverage

  • Search functionality not working as expected
  • Search results not grouped correctly
